# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/YOURUSERNAME/Rice-in-win-10
```

---

# 🖥️ Windows Terminal

Copy:

```txt
windows-terminal/settings.json
```

To:

```txt
C:\Users\YOURUSERNAME\AppData\Local\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\
```

---

# ⚡ Fastfetch

Copy:

```txt
fastfetch/config.jsonc
```

To:

```txt
C:\Users\YOURUSERNAME\.config\fastfetch\
```
